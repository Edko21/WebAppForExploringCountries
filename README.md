Technologies: JavaScript, HTML, CSS, REST Countries API

A multi-page web application for exploring countries and their geographical information using live data from the REST Countries API. Users can select geographical regions, browse country listings, search by name, sort countries alphabetically, and view detailed information such as capitals, area, currencies, languages, time zones, and neighboring countries.

The project demonstrates asynchronous data fetching, dynamic DOM rendering, client-side filtering and sorting, and navigation using URL query parameters.
